📤 Upload Management

📄 Transcript Upload

POST/episodes/{episodeId}/transcripts - Upload Transcript
Uses the Episode ID from the Episodes tab. File will be uploaded directly to S3.

🎥 Video Track Upload (Multipart)

POST/episodes/{episodeId}/tracks - Initiate Track Upload
Multi-step process: Initiate → Sign Parts → Upload Parts → Complete Upload
Ensure your S3 bucket CORS exposes the ETag header for part uploads.

✂️ Clip Management

GET/episodes/{episodeId}/clips - List Clips
Uses the Episode ID from the Episodes tab. Click on clip IDs to use them below.
GET/episodes/{episodeId}/clips/{clipId} - Get Clip Details
PATCH/episodes/{episodeId}/clips/{clipId} - Update Clip Status
Uses the Episode ID and Clip ID from the fields above.
GET/episodes/{episodeId}/clips/{clipId}/play - Play Clip
Generates a download URL for the clip video file and increments view count. Uses Episode ID and Clip ID from above.
DELETE/episodes/{episodeId}/clips/{clipId} - Delete Clip
⚠️ This will permanently delete the clip and all associated files. Uses Episode ID and Clip ID from above.

🎵 Track Management

PUT/episodes/{episodeId}/tracks/{trackName} - Update Track Metadata
Uses the Episode ID from the Episodes tab. Updates the speakers array for the specified track.
Empty speakers field will remove all speakers from the track.
